# Book Logger - 読書記録アプリ

読書記録を管理するRailsアプリケーション。書籍の登録・レビュー・タグ付けができる。

※デプロイは不要でローカルで動作するアプリケーションが完成すれば良い

# 機能

実際のイメージは[モックサイト](https://ysmb-wtsg.github.io/bookshelf/login.html)を参考にすること。

## ユーザー認証

- ユーザー新規登録（ユーザー名・メールアドレス・パスワード）
- ログイン / ログアウト

## 書籍管理

- 書籍一覧表示（カード形式、ページネーション付き）
- 書籍登録（タイトル・著者・説明・タグ）
- 書籍詳細表示（書籍情報・平均評価・レビュー一覧）
- 書籍編集
- 書籍削除

## レビュー

- レビュー投稿（評価（1〜5）・タイトル・本文）
- 書籍詳細ページでのレビュー一覧表示

## 検索・フィルタ

- キーワード検索（タイトル・著者名）
- タグによる絞り込み（プルダウン選択 / タグバッジによるクイックフィルタ）

## タグ

- 書籍へのタグ付け（Ruby, 設計, 小説, ビジネス, 自己啓発 など）
- タグによる書籍のフィルタリング

# 開発フロー

## Issue駆動開発

本プロジェクトではIssue駆動で開発を進める。すべての変更はIssueを起点とし、PRを経由してmainにマージする。

### フロー

1. **Issue作成** — プロジェクトオーナーが機能追加・バグ修正などのIssueを作成する
2. **ブランチ作成** — 実装者はIssueに対応するブランチを切る（命名規則: `feature/#{issue番号}`）
3. **実装・Push** — 実装が完了したらリモートにPushする
4. **PR作成** — mainブランチへのPRを作成し、対応するIssueを紐づける
5. **レビュー** — プロジェクトオーナーがコードレビューを行う
6. **マージ** — レビュー承認後、mainブランチにマージする

### ルール

- mainへの直接push禁止。必ずPR経由でマージする
- 1つのPRは1つのIssueに対応させる
